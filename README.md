# قالب موقع مطعم (Restaurant Website Template)

قالب موقع ويب لمطعم، قابل لإعادة الاستخدام، يتيح للزوار تصفح المنيو وتقديم طلباتهم عبر واتساب.

## التقنيات المستخدمة

* Next.js
* React
* TypeScript
* Tailwind CSS
* Lucide
* خط Cairo

## نطاق العمل

قالب Frontend فقط، عربي أولاً، باتجاه من اليمين لليسار (RTL)، مصمم أولاً للموبايل، مع نظام طلب عبر واتساب.

## البدء

```bash
npm install
npm run dev
```

## ملاحظات المشروع

* `BRD.md` يحتوي على متطلبات المنتج ونطاق العمل.
* `AGENTS.md` يحتوي على قواعد التطوير الخاصة بالوكلاء الذكيين (AI Agents).
* محتوى كل مطعم يجب أن يظل قابلاً للتهيئة.
